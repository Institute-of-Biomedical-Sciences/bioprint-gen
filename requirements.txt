# BioprintGEN runtime dependencies.  Requires Python 3.10+ (verified on 3.12).
#
# The pins below are *minimum* versions (">=") — the lowest release whose API we
# rely on.  On a fresh `pip install -r requirements.txt` this resolves to the
# newest compatible release, so a clean install gets the latest automatically.
# It does NOT upgrade packages that are already installed; for that use:
#
#     pip install -U -r requirements.txt
#
# Versions in brackets are what this build was verified against (all current on
# PyPI as of 2026-07-23, except contourpy where 1.3.3 is latest and 1.2.1 also
# works).

# --- imported directly by BioprintGEN ---
PySide6>=6.6           # Qt GUI: widgets, QGraphicsView preview, markdown help   [6.11.1]
numpy>=1.24            # vector math throughout                                   [2.5.1]
shapely>=2.0           # 2D geometry: insets, clipping, hole handling, covers()   [2.1.2]
